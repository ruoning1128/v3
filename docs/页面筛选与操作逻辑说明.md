# 云机管理原型页面筛选与操作逻辑说明

更新时间：2026-07-27  
适用范围：`prototype/index.html` 当前静态原型

## 1. 通用规则

### 1.1 筛选区通用行为

- `搜索`：当前原型保留筛选区与结果刷新反馈，点击后出现“查询完成”提示。
- `重置`：清空当前页面所有 `data-filter` 筛选控件。
- 当前原型筛选项主要用于展示页面结构与交互口径，暂未接入真实后端查询。

### 1.2 导出通用行为

- `下载全部`、`导出订购`、`导出到期清单`、`导出日志` 等导出类按钮会模拟生成导出任务。
- 导出动作会写入操作日志，日志对象为 `EXPORT` 或对应导出对象。

### 1.3 权限通用规则

当前原型通过右上角角色切换模拟权限：

| 角色 | 默认能力 |
| --- | --- |
| 超级管理员 | 全部允许 |
| 运营管理员 | 全部允许 |
| 实施/客服 | 允许绑定/解绑、发起更换退回相关能力 |
| 商务/财务 | 允许续期相关能力 |
| 只读/审计 | 只读，操作按钮置灰或不可执行 |

高风险操作包括更换、退回、正式到期处理、导出等，原型会通过提示、二次确认弹窗或日志模拟体现。

## 2. 云机概览

### 2.1 页面定位

用于查看云机资源总体分布、关键状态和生命周期流转入口。

### 2.2 筛选项

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 合作方 | 下拉 | 可选微联、有机云 |
| 设备类型 | 下拉 | 可选云手机、云 PAD |
| 状态 | 下拉 | 使用云机状态枚举 |
| 客户名称 | 输入框 | 输入客户名称 |
| 项目名称 | 输入框 | 输入项目名称 |
| 到期区间 | 下拉 | 可选 7 天内、30 天内、已到期 |

### 2.3 页面功能

- `下载全部`：导出当前概览数据，写入导出审计。
- `采购入库`：打开采购入库弹窗，确认后新增一台公共池可用云机。
- `新增订购`：打开新增客户订购弹窗，确认后新增一条待库存校验的订购单。
- `重置`：清空筛选项。
- `搜索`：展示查询完成反馈。

### 2.4 指标跳转规则

| 指标 | 跳转页面 | 带入口径 |
| --- | --- | --- |
| 公共池可用 | 公共云机池 | 公共池可用 |
| 客户池空闲 | 客户云机池 | 客户池空闲 |
| 项目使用中 | 客户云机池 | 项目使用中 |
| 续期/禁用保护 | 运维中心 | 到期处理相关 |
| 待检测/维护 | 公共云机池 | 待检测 |

### 2.5 表格操作

概览表格展示前 6 条云机资源，用于快速查看详情。点击云机 ID 可打开详情弹窗，查看归属、状态、客户、账号和最近日志。

## 3. 公共云机池

### 3.1 页面定位

运营维护可分配库存，只允许“公共池可用”资源进入客户分配候选。

### 3.2 筛选项

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 云机ID | 输入框 | 精确或模糊输入云机 ID |
| 设备类型 | 下拉 | 云手机、云 PAD |
| 合作方 | 下拉 | 微联、有机云 |
| 资源状态 | 下拉 | 公共池可用、待检测、待维护、暂停使用 |
| 合作方到期 | 下拉 | 90 天内、180 天内、一年内 |
| 入库来源 | 输入框 | 采购单或入库批次 |

### 3.3 页面功能

- `导入入库`：打开采购入库弹窗，确认后新增公共池可用云机。
- `批量导出`：进入批量导出模式，表格出现复选框。
- `批量检测`：进入批量检测模式，表格出现复选框。
- `重置`、`搜索`：同通用规则。

### 3.4 批量模式规则

进入批量模式后：

- 表格首列出现复选框，可单选或全选。
- 选中行会高亮。
- 未选中行的 `分配`、`检测` 按钮置灰。
- 选中行可继续点击行内 `分配` 或 `检测`。
- `清空选择`：清除所有已选云机。
- `取消`：退出批量模式并清空选择。
- `确认导出`：必须至少选择 1 台云机，确认后生成导出任务并写入日志。
- `确认检测`：必须至少选择 1 台云机；选中的待检测/待维护资源会模拟变为公共池可用。

### 3.5 表格操作按钮规则

| 按钮 | 可点击条件 | 点击结果 |
| --- | --- | --- |
| 云机 ID | 始终可点击 | 打开云机详情和最近日志 |
| 分配 | 状态为公共池可用；角色有分配权限；若在批量模式下，该行必须被选中 | 打开分配弹窗，确认后云机转入客户云机池 |
| 检测 | 状态为待检测或待维护；角色有检测权限；若在批量模式下，该行必须被选中 | 状态转为公共池可用 |
| 暂停 | 角色有检测/维护权限 | 状态转为暂停使用 |

## 4. 客户订购

### 4.1 页面定位

运营处理客户租赁需求、库存校验和确认分配。

### 4.2 筛选项

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 客户名称 | 输入框 | 输入客户名称 |
| 订购状态 | 下拉 | 草稿、待库存校验、待分配确认、库存不足、已分配、已取消 |
| 设备类型 | 下拉 | 云手机、云 PAD |
| 创建人 | 输入框 | 输入创建人 |
| 开始时间 | 日期控件 | 可选择年月日 |
| 结束时间 | 日期控件 | 可选择年月日 |

### 4.3 页面功能

- `新增订购`：打开新增客户订购弹窗，保存后新增待库存校验订购单。
- `导出订购`：生成订购导出任务并写入导出审计。
- `重置`、`搜索`：同通用规则。

### 4.4 表格操作按钮规则

| 按钮 | 可点击条件 | 点击结果 |
| --- | --- | --- |
| 库存校验 | 角色有分配权限 | 检查公共池中同设备类型的公共池可用资源；库存足够则状态变为待分配确认，不足则状态变为库存不足 |
| 确认分配 | 订购状态为待分配确认；角色有分配权限 | 将公共池可用云机分配到客户云机池，订购状态变为已分配；若库存不足则保持库存不足 |
| 取消 | 订购状态不是已分配；角色有分配权限 | 订购单状态变为已取消，不改变库存归属 |

## 5. 客户云机池

### 5.1 页面定位

查看客户名下云机资源，并执行绑定、项目分配、项目回收、更换、退回、续期等操作。

### 5.2 筛选项

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 客户ID/名称 | 输入框 | 输入客户 ID 或客户名称 |
| 项目名称 | 输入框 | 输入项目名称 |
| 企微账号 | 输入框 | 输入企微账号 |
| 保护期状态 | 下拉 | 客户池空闲、项目使用中、续期保护期、禁用保护期 |
| 客户到期日 | 日期控件 | 可选择年月日 |
| 云机ID | 输入框 | 输入云机 ID |

### 5.3 页面功能

- `重置`、`搜索`：同通用规则。
- 页面本身不提供新增按钮，核心操作集中在表格行内。

### 5.4 表格操作按钮规则

| 按钮 | 可点击条件 | 点击结果 |
| --- | --- | --- |
| 云机 ID | 始终可点击 | 打开云机详情和最近日志 |
| 绑定 | 云机状态为客户池空闲；角色有绑定权限 | 打开绑定企微账号弹窗，确认后写入企微账号、真人身份、应用、登录状态 |
| 分配项目 | 云机状态为客户池空闲；角色有分配权限 | 云机状态变为项目使用中，归属变为客户项目 |
| 项目回收 | 云机状态为项目使用中；角色有更换/退回权限 | 解除项目绑定，云机回到客户云机池，不进入公共池 |
| 更换 | 角色有更换/退回权限 | 打开更换确认弹窗；确认后旧机回公共池待检测，新机进入客户云机池 |
| 退回 | 角色有更换/退回权限 | 打开退回确认弹窗；确认后解除客户、项目、账号关系，云机进入公共池待检测 |
| 续期 | 角色有续期权限 | 打开续期弹窗，确认后到期日更新为新日期并恢复正常状态 |

## 6. 绑定管理

### 6.1 页面定位

集中维护云机与企微账号、真人身份、应用和登录状态的绑定关系。

### 6.2 筛选项

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 企微账号 | 输入框 | 输入企微账号 |
| 真人身份 | 输入框 | 输入真人身份 |
| 应用 | 下拉 | 企微助手、群运营 |
| 登录状态 | 下拉 | 在线、离线、限制登录 |
| 云机ID | 输入框 | 输入云机 ID |
| 客户名称 | 输入框 | 输入客户名称 |

### 6.3 表格操作按钮规则

| 按钮 | 可点击条件 | 点击结果 |
| --- | --- | --- |
| 变更 | 角色有绑定权限 | 打开绑定弹窗，可更新企微账号、真人身份、应用和登录状态 |
| 解绑 | 角色有绑定权限 | 清空企微账号、真人身份、应用和登录状态，并写入操作日志 |
| 日志 | 始终可点击 | 打开云机详情弹窗，查看最近日志 |

## 7. 运维中心

运维中心合并了原“更换/退回工单”“续期到期中心”“配置中心”三个页面，减少空页面并集中处理后置运维动作。

### 7.1 顶部汇总

| 指标 | 说明 |
| --- | --- |
| 待跟进工单 | 当前更换/退回工单数量 |
| 当前到期筛选 | 当前到期阶段筛选下的资源数量 |
| 启用合作方 | 当前启用的合作方数量 |

### 7.2 更换/退回工单模块

页面按钮：

| 按钮 | 说明 |
| --- | --- |
| 新建更换工单 | 打开工单弹窗，默认创建更换类工单 |
| 新建退回工单 | 打开工单弹窗，默认创建退回类工单 |

表格按钮：

| 按钮 | 可点击条件 | 点击结果 |
| --- | --- | --- |
| 审批 | 工单状态为待审批；角色有更换/退回权限 | 工单状态变为待处理 |
| 完成处理 | 角色有更换/退回权限 | 工单状态变为已完成；结果按更换或退回展示 |

### 7.3 续期到期模块

阶段筛选：

- 全部
- 正常使用期
- 续期保护期
- 禁用保护期
- 正式到期处理

页面按钮：

| 按钮 | 说明 |
| --- | --- |
| 执行日终到期检查 | 模拟系统日终任务，将已到期且仍在项目使用中的资源流转到续期保护期 |
| 导出到期清单 | 生成导出任务并写入导出审计 |

表格按钮：

| 按钮 | 可点击条件 | 点击结果 |
| --- | --- | --- |
| 续期 | 角色有续期权限 | 打开续期弹窗；确认后更新客户到期日，恢复为项目使用中或客户池空闲 |
| 转禁用 | 云机状态为续期保护期；角色有续期权限 | 状态转为禁用保护期，登录状态变为限制登录 |
| 正式回收 | 云机状态为禁用保护期；角色有更换/退回权限 | 解除客户、项目、账号关系，回到公共池待检测 |

### 7.4 配置中心模块

页面按钮：

| 按钮 | 可点击条件 | 点击结果 |
| --- | --- | --- |
| 新增合作方 | 角色有配置权限 | 模拟配置新增，并写入日志 |
| 按库存均分 | 角色有配置权限 | 模拟分配比例重置，并写入日志 |

表格按钮：

| 按钮 | 可点击条件 | 点击结果 |
| --- | --- | --- |
| 编辑 | 角色有配置权限 | 模拟配置维护，并写入日志 |
| 启用/停用 | 角色有配置权限 | 切换合作方启用状态，并写入日志 |

## 8. 操作日志

### 8.1 页面定位

用于排查和审计，记录采购、入库、分配、绑定、解绑、项目回收、更换、退回、续期、到期处理、导出等动作。

### 8.2 筛选项

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 对象ID | 输入框 | 输入云机、客户、项目或账号 |
| 动作 | 下拉 | 采购入库、库存分配、项目分配、项目回收、更换、退回、续期、到期处理、导出 |
| 操作人 | 输入框 | 输入操作人 |
| 结果 | 下拉 | 成功、阻断、失败 |
| 开始时间 | 输入框 | 当前原型暂为文本输入 |
| 结束时间 | 输入框 | 当前原型暂为文本输入 |

### 8.3 页面功能

- `导出日志`：生成日志导出任务并写入导出审计。
- 日志表格只读，不提供删除或修改操作。

## 9. 主要状态流转摘要

| 操作 | 前置状态 | 成功后状态/归属 |
| --- | --- | --- |
| 采购入库 | 无 | 新云机进入公共池可用 |
| 库存分配 | 公共池可用 | 客户池空闲，归属客户云机池 |
| 绑定企微 | 客户池空闲 | 写入账号绑定关系，状态不必然变化 |
| 分配项目 | 客户池空闲 | 项目使用中，归属客户项目 |
| 项目回收 | 项目使用中 | 客户池空闲，归属客户云机池 |
| 更换 | 客户名下资源 + 公共池有可用新机 | 旧机进入公共池待检测，新机进入客户云机池 |
| 退回 | 客户不再使用且无阻断 | 解除客户/项目/账号关系，进入公共池待检测 |
| 续期 | 客户名下资源 | 更新客户到期日，恢复正常使用 |
| 转禁用 | 续期保护期 | 禁用保护期，限制登录 |
| 正式回收 | 禁用保护期 | 解除绑定，进入公共池待检测 |
